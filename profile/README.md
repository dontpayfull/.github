## Open source

| Project | What it does |
|---|---|
| [AInotate](https://github.com/dontpayfull/AInotate) | Annotated screenshots for AI agents: numbered steps, Skitch-style arrows, boxes, labels and solid redaction, placed where they cover the least content. CLI, MCP server and agent skill. `pipx install "ainotate[all]"` or `brew install dontpayfull/tap/ainotate` |
| [AI Terminal Sessions](https://github.com/dontpayfull/ai-terminal-sessions) | Persistent tmux terminals for Cursor and VS Code that survive editor restarts, with live status for Claude Code, Codex, Antigravity, Grok and OpenCode: working or waiting, context use, cost and last messages. Browse, name and resume every past conversation. Install from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=visul.terminal-sessions) or [Open VSX](https://open-vsx.org/extension/visul/terminal-sessions) |
